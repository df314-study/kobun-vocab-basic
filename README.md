# 古文単語 Master

スマートフォン・タブレット向けの古文単語学習PWAです。

## 実装済み
- 2段階判定：①自信あり/なし → ②正解/不正解
- 回答時間を計測し、3秒以上なら弱点スコアを追加
- 不正解・自信なしを強く弱点化
- 弱点優先出題
- 今日の学習 / 苦手 / 復習 / 基礎 / 標準 / 発展
- 全単語一覧、検索、重要度表示
- 品詞・活用表示
- 1日の学習語数を設定
- IndexedDBによる端末保存
- JSONバックアップ/復元
- JSON/CSVによる単語追加
- PWA / オフライン対応

## 単語データの形式
JSONは次の配列形式で追加できます。

[
  {
    "word":"あはれ",
    "meaning":"しみじみとした趣・感動",
    "pos":"名詞・形容動詞",
    "conj":"—",
    "level":"基礎"
  }
]

CSVの見出し：
word,meaning,pos,conj,level

## 起動方法
PWAとして使う場合はHTTPSで配信してください。GitHub Pages、Netlify、Vercelなどに配置すると、スマートフォンのホーム画面へ追加できます。

ローカルで単にindex.htmlを開く方法でも画面確認はできますが、Service Workerによるオフライン機能はHTTPS等の安全なコンテキストで利用する必要があります。

## データについて
同梱の12語は動作確認用のスターターデータです。アップロードされた教材の全語彙を公開用に再配布することはせず、個人学習用のデータとして利用してください。
