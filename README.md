# 古文単語 Master v16

v15の610語マスターを維持し、学習履歴を引き継ぎながら習得判定と出題制御を追加した版です。

- 収録語数：610語
- 難易度：基礎 / 標準 / 発展
- 3秒以内の正解を3回連続で達成した単語を「習得済み」と判定
- 習得済み単語数をホーム画面に表示
- 一覧画面で「習得 / 未習得 / 全単語」と重要度を独立してフィルター可能
- 3秒以内に正解した単語は、その日の残りは出題しない
- 習得済み単語は原則7日間出題しない。その後も出題優先度を大きく下げる
- 習得していないが、直近の別日に3秒以内で正解した単語は、習得を目指して重点的に出題
- v15までの学習履歴（stats）は対応する単語について維持
- 「行幸」「御幸」を削除し、「みゆき(行幸・御幸)」のみ収録
