# 古文語彙マスター PWA v7（語彙の追加・更新対応版）

## v7の変更点
- CSV/JSONの語彙インポートを「追加」だけでなく「更新」に対応。
- 同じ `id` の単語を再インポートすると、単語情報だけ更新し、既存の学習履歴（stats）を維持します。
- `id` がないデータでも、同じ単語名から安定したIDを作るため、同じ単語を再インポートした際に重複しにくくなっています。
- CSVの引用符（カンマを含む意味など）にも対応しています。
- インポート後に「新規・更新・無効」の件数を表示します。
- IndexedDBをv5へ更新します。既存データは保持されます。

## 語彙データの範囲
v7の初期収録データは、前版と同じ315語セットです。アップロードされた索引の現代語訳付き項目すべてを照合した完成版ではありません。

## 全件データを後から入れる方法
1. 設定画面を開く。
2. 「単語データ(JSON/CSV)を追加・更新」を選ぶ。
3. CSVまたはJSONを選択する。
4. 同じ `id` のデータは上書きされますが、既存の学習履歴は引き継がれます。

推奨CSV列：`id,word,meaning,pos,conj,level`

例：
```csv
id,word,meaning,pos,conj,level
example-001,あはれ,しみじみとした趣・感動,名詞・形容動詞,—,基礎
example-002,をかし,趣がある・おもしろい,形容詞,シク活用,基礎
```

## バックアップ
学習履歴・設定はブラウザのIndexedDBに保存されます。データを移す前に「バックアップを書き出す」を利用してください。
